================================================================================
  THE CORE ALGORITHM (30 Seconds)
================================================================================

For each vertebra:
  1. Read 3D binary mask
  2. Center at center of mass
  3. Compute inertia tensor (3×3 matrix)
  4. Find eigenvalues/eigenvectors (principal axes)
  5. For each voxel: project onto 3 axes → determine region
  6. Output: 8 regions (Superior/Inferior × Anterior/Posterior × Left/Right)

Math level: Linear algebra (eigendecomposition)
Complexity: O(N) where N = number of voxels
Time: ~100ms per vertebra
Result: Anatomically meaningful segmentation
